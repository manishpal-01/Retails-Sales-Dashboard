# Retails-Sales-Dashboard (Power BI)

This project is an interactive Retail Sales Dashboard created using Microsoft Power BI. The dashboard provides a clear overview of sales performance, revenue, profit, products, categories, and regional sales.
## Tools & Technologies
Microsoft Power BI
Power Query – Data Cleaning & Transformation
DAX – Measures & Calculations
Microsoft Excel – Data Source

## Dashboard Highlights
Total Sales
Total Profit
Total Units Sold
Profit Margin
Sales & Profit by Category
Sales & Profit by Sub-Category
Top 10 Products by Profit
Unit Price vs Units Sold
Regional Performance
Interactive Filters & Slicers

## Data Workflow

 #### Raw Data → Power Query → Data Cleaning → Data Modeling → DAX Measures → Data Visualization → Interactive Dashboard
